ezyReader 개인정보처리방침

게시자: koProDev · 시행일: 2026-10-01 · 적용 버전: 0.1.9

English privacy policy

ezyReader는 사용자가 선택한 웹페이지 또는 텍스트를 읽기 편한 화면으로 표시하는 Chrome 확장 프로그램입니다. 계정을 만들거나 로그인할 필요가 없습니다.

처리하는 정보와 목적

  • 웹사이트 콘텐츠: 사용자가 읽기를 실행한 페이지의 본문·선택한 텍스트·제목·작성자·이미지 및 미디어 주소 등을 브라우저 안에서 처리해 읽기 화면을 만듭니다.
  • 페이지 주소와 탭 정보: 읽기를 실행한 페이지의 URL과 탭·프레임 식별자를 본문 표시, 원문 링크, 읽기 화면 관리에 사용합니다. 전체 방문 기록을 조회하는 history 권한을 사용하지 않으며 방문 내역 목록을 만들지 않습니다.
  • 읽기 설정: 글자 크기·글꼴·줄 간격·본문 폭·보기 방식·테마·미디어 표시·툴바 위치와 설정 관리용 메타데이터를 기기에 저장합니다. 설정 메타데이터에는 변경 시각과 무작위로 생성한 기기별 식별자가 포함됩니다. 이 식별자는 계정·광고 식별자가 아니며 외부로 전송하지 않습니다.

저장과 삭제

추출한 본문과 페이지 주소는 메모리 기반 chrome.storage.session에 잠시 저장했다가 읽기 화면에 표시된 뒤 삭제합니다. 표시 중인 본문은 읽기 화면 안에 남습니다. 화면 관리용 식별자는 해당 읽기 세션을 정리할 때 삭제하며 브라우저 재시작·확장 재로드 시 세션 저장소도 초기화됩니다. 시크릿 탭의 본문은 영구 저장하지 않습니다.

설정과 설정 관리용 메타데이터는 chrome.storage.local에 보관합니다. 확장 프로그램을 제거하면 해당 확장 저장소가 삭제됩니다. ezyReader는 본문·페이지 주소·설정을 개발자 서버로 보내지 않으며 원격 계정 동기화·광고·분석 SDK를 사용하지 않습니다.

외부 서비스와 네트워크 요청

  • Google Fonts: Noto 글꼴을 선택하면 fonts.googleapis.com과 fonts.gstatic.com에서 CSS·글꼴 파일을 불러옵니다. 기본 글꼴은 Noto 고딕입니다. 본문 텍스트를 글꼴 요청에 넣지 않습니다. ‘시스템’ 글꼴을 선택하면 Google Fonts 요청을 하지 않습니다.
  • 원문 미디어: 본문 이미지·포스터 등은 원래 리소스 주소에서 Referer 없이 다시 불러옵니다. 오디오·동영상은 재생 시 요청하며 쪽 보기에서는 다음 펼침의 이미지를 미리 불러올 수 있습니다.
  • YouTube·X: 기본값인 ‘링크로 보기’에서는 임베드를 불러오지 않습니다. ‘그 자리에 보기’를 선택하면 youtube-nocookie.com 및 platform.twitter.com의 격리된 프레임으로 동영상·게시물을 불러옵니다. YouTube는 별도 선택 권한을 요구하며 플레이어 요청의 Referer에는 원문 URL 대신 확장 프로그램 ID를 사용합니다.

외부 리소스 요청을 받는 서버는 IP 주소·브라우저 요청 정보·요청한 리소스 주소 등을 알 수 있습니다. 쿠키 등은 브라우저 설정과 해당 서비스의 정책에 따라 처리됩니다. 관련 서비스에는 Google 개인정보처리방침과 X 개인정보처리방침이 적용됩니다. 원문 미디어에는 원래 제공자의 정책이 적용됩니다.

권한

storage는 설정과 임시 본문 보관, activeTab과 scripting은 사용자가 실행한 페이지의 본문 추출·읽기 화면 표시, contextMenus는 우클릭 명령에 사용합니다. declarativeNetRequestWithHostAccess와 선택적 youtube-nocookie.com 접근 권한은 사용자가 요청한 YouTube 임베드 재생에만 사용합니다.

데이터 사용 원칙과 문의

사용자 데이터는 읽기 기능을 제공하는 데만 사용합니다. 사용자 데이터를 판매하거나 광고·신용도 판단·대출 목적으로 사용하지 않습니다. ezyReader의 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

문의는 ezyReader GitHub 지원 또는 Chrome 웹 스토어의 개발자 연락처를 이용해 주세요. 공개 문의에는 개인정보나 읽던 본문을 포함하지 마세요. 기능이나 데이터 처리 방식이 바뀌면 이 문서의 시행일과 내용을 갱신합니다.

ezyReader Privacy Policy

Publisher: koProDev · Effective: October 1, 2026 · Version: 0.1.9

ezyReader displays a user-invoked web page or selected text in a customizable reading view. No account or sign-in is required.

Information handled and purpose

The extension processes website content, including article text, selected text, titles, authors, and image/media URLs, locally in the browser. It uses the invoked page URL and tab/frame identifiers to display the article, link to the original, and manage the reader. It does not use the history permission, access the full browsing history, or maintain a list of visited pages.

Reading preferences and settings metadata are saved locally. Metadata includes modification times and a randomly generated device-specific identifier for settings management. This identifier is not an account or advertising identifier and is not transmitted externally.

Retention and deletion

Extracted content and page URLs are temporarily held in memory-backed chrome.storage.session and removed after rendering. The displayed article remains within the open reader. Reader-management identifiers are removed during session cleanup; browser restart or extension reload clears session storage. Incognito article content is not written to persistent storage.

Preferences and settings metadata remain in chrome.storage.local until removed with the extension. ezyReader does not send article text, page URLs, or settings to a developer server. It has no remote account sync, advertisements, or analytics SDK.

External requests

  • Fonts: Noto fonts, including the default sans-serif font, load CSS and font files from fonts.googleapis.com and fonts.gstatic.com. Article text is not included in font requests. Selecting System prevents Google Fonts requests.
  • Original media: Images and posters load from their original resource hosts without a Referer header. Audio and video are requested on playback. Page-turning views may preload images on the next spread.
  • Optional embeds: Links only is the default. Choosing inline media loads YouTube and X content in isolated frames from youtube-nocookie.com and platform.twitter.com. YouTube requires an optional host permission. Its player request uses the extension ID as Referer, not the source article URL.

Resource providers receive network information such as your IP address, browser request information, and requested resource URLs. Cookies depend on your browser settings and the provider's policies. See the Google Privacy Policy, the X Privacy Policy, and the original media provider's policy.

Permissions and limited use

storage supports preferences and temporary article transfer; activeTab and scripting extract the user-invoked page and display the reader; contextMenus enables right-click reading actions. declarativeNetRequestWithHostAccess and optional youtube-nocookie.com access support user-requested YouTube embeds only.

User data is used only to provide reading features. It is not sold or used for advertising, creditworthiness, or lending. ezyReader's use of data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Contact and changes

For questions, use ezyReader GitHub support or the developer contact information on the Chrome Web Store. Do not include personal information or article content in public issues. This policy and its effective date will be updated when functionality or data handling changes.
